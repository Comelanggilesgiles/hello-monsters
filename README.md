# Hello, Monsters!

A playful, animated landing page for a children's English conversation school.

## Description

Hello, Monsters! is a single-page website for a fictional English conversation school for kids aged 4 to 12. It is built with plain HTML, CSS, JavaScript and inline SVG, so there is nothing to install and nothing to build. Open one file and it runs.

The page uses a bold yellow and light blue palette, original monster characters drawn in SVG, and a roughly 3 second opening animation where monsters fly in from all four sides. It works on desktop and smartphone and includes a free trial form with real validation.

All names, fees and reviews on the page are sample content. Replace them with your own before publishing.

## Key features

- Opening animation: five monsters enter from the top, bottom, left and right, then the title pops in letter by letter.
- Eyes that follow: every monster's eyes track the mouse or finger.
- Pointer follower: a small monster trails behind the cursor.
- Peeking monsters: monsters rise up from the edge of each section as you scroll, and rise higher on hover.
- Scroll progress: a monster rides along the progress bar at the top of the page.
- Click and tap fun: clicking anywhere shows a speech bubble, and clicking a monster makes it jump.
- Full landing page content: classroom features, courses, instructors, fees, parent reviews, FAQ and a free trial form.
- Working form: required-field checks, email format check, inline error messages, keyboard focus, and a thank-you state.
- Responsive layout for phones, tablets and desktops.
- Respects the "reduce motion" setting and supports light and dark system themes.
- No images, no frameworks and no build step. All monsters are SVG generated by JavaScript.

## Install and run (under 5 minutes)

You need only a modern web browser (Chrome, Edge, Firefox or Safari). An internet connection is recommended so the Fredoka font loads from Google Fonts. Without it the page falls back to a system font.

### Option A: open the file directly

1. Download the project. Click the green **Code** button on GitHub, then **Download ZIP**, and unzip it.
2. Double-click `index.html`.

### Option B: run a local server

1. Clone the repository:

   ```bash
   git clone https://github.com/Comelanggilesgiles/hello-monsters.git
   cd hello-monsters
   ```

2. Start a local server (needs Python 3):

   ```bash
   python3 -m http.server 8000
   ```

3. Open <http://localhost:8000> in your browser.

## Usage

- Scroll down the page to see the monsters peek out and the progress bar fill.
- Move your mouse (or drag your finger) to make the eyes follow.
- Click or tap monsters and the background for jumps and speech bubbles.
- Fill in the form at the bottom and press **Book the free trial**. Leave a field empty to see the error messages.

### Make it yours

- Text, fees, teachers and reviews: edit the HTML in `index.html`.
- Colors: change the variables at the top of the `<style>` block (`--y` yellow, `--s` light blue, `--n` navy).
- Monsters: edit the `SV` object in the `<script>` block. Each monster is a short list of SVG shapes.
- Form submission: the form currently shows a thank-you message and sends nothing. Search for `To go live` in `index.html` and send `new FormData(F)` to your email or booking service there.

## Publish it for free with GitHub Pages

1. Push the project to GitHub (see the steps below).
2. On the repository page, open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then **Save**.
4. After a minute your site is live at `https://comelanggilesgiles.github.io/hello-monsters/`.

## Tech stack

- HTML5
- CSS3: custom properties, grid, flexbox, keyframe animations, media queries
- JavaScript (ES6, no libraries): DOM, IntersectionObserver, Web Animations API, pointer events
- Inline SVG for all characters and decorations
- Google Fonts: Fredoka

## Contributing and committing

Contributions are welcome. If you have never used Git, follow these steps.

1. Install Git from <https://git-scm.com> and check it with `git --version`.
2. Fork this repository with the **Fork** button on GitHub.
3. Clone your fork and enter the folder:

   ```bash
   git clone https://github.com/<your-username>/hello-monsters.git
   cd hello-monsters
   ```

4. Create a branch for your change:

   ```bash
   git checkout -b my-change
   ```

5. Edit `index.html`, then refresh the browser to check it.
6. Stage and commit your work with a short, clear message:

   ```bash
   git add .
   git commit -m "Add a new monster to the hero"
   ```

7. Push the branch to your fork:

   ```bash
   git push -u origin my-change
   ```

8. On GitHub, click **Compare & pull request**, describe what you changed, and submit.

Please keep changes small, test on both a desktop and a phone-size window, and do not add copyrighted characters or images.
